# موعدي — Mawidi

نظام حجز مواعيد طبية: واجهة للمريض (`/`) ولوحة طبيب محمية (`/doctor/login`).
**بلا أي حزم خارجية**: Node.js ≥ 22.13 + قاعدة SQLite مدمجة (`node:sqlite`).

## التشغيل
```bash
npm run create-doctor     # ينشئ حساب الطبيب الوحيد (يسأل عن الاسم وكلمة المرور، 10 أحرف على الأقل)
npm start                 # http://localhost:3000
npm test                  # اختبار تكاملي (12 سيناريو)
```
لا توجد كلمة مرور افتراضية. الأمر `create-doctor` يرفض العمل إن وُجد حساب مسبقًا؛ التغيير لاحقًا من صفحة «الأمان».

## متغيرات البيئة
| المتغير | الوصف |
|---|---|
| `PORT` | المنفذ (3000) |
| `DB_PATH` | مسار ملف القاعدة (`data/mawidi.db`) — **يجب أن يكون على قرص دائم** |
| `NODE_ENV=production` | يفعّل وسم `Secure` على الكوكي (يتطلب HTTPS) |
| `TZ_OFFSET_MIN` | فرق التوقيت عن UTC بالدقائق (60 = الجزائر) |
| `TRUST_PROXY=1` | عند الاستضافة خلف وكيل عكسي، لتحديد IP الحقيقي في تحديد المعدّل |

## النشر
يحتاج خادمًا يشغّل Node ويملك **قرصًا دائمًا** (VPS، Fly.io مع Volume، Railway مع Volume، Render مع Persistent Disk). لا تستخدم استضافة بنظام ملفات مؤقت (Vercel/Netlify) وإلا ضاعت البيانات. ضع الموقع خلف HTTPS (Caddy أو Nginx)، وخذ نسخة احتياطية دورية من `data/`.

## ملاحظات
- التحقق من تعارض المواعيد في القاعدة نفسها (فهرس فريد على التاريخ+الساعة للحالتين «في الانتظار» و«مؤكد»)، فلا يمر حجزان لنفس الفترة حتى مع الطلبات المتزامنة.
- الطلب المعلّق يحجز الفترة إلى أن يرفضه الطبيب أو يلغيه.
- كلمات المرور: scrypt مع ملح. الجلسات: رمز عشوائي في كوكي HttpOnly/SameSite=Strict، ويُخزَّن مجزّأً في القاعدة.
- حد المحاولات (في الذاكرة): 6 محاولات دخول/15 دقيقة، و8 حجوزات/ساعة لكل IP.
- التوطين: النصوص العربية في ملفات `public/*.js`؛ إضافة الفرنسية لاحقًا تتطلب استخراجها إلى ملف ترجمة.
- حماية البيانات: يُنصح بمراجعة القانون الجزائري 18-07 (حماية الأشخاص الطبيعيين في معالجة المعطيات ذات الطابع الشخصي) وإضافة سياسة خصوصية رسمية.
